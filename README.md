# FinWell — Financial Wellness Platform

Interview-ready starter project for Software Development + DevOps preparation.

## Requirements
- Node.js 22+
- npm
- MongoDB running locally

## Run backend
```powershell
cd backend
copy .env.example .env
npm install
npm run dev
```

Backend: http://localhost:5000

## Run frontend
Open a second terminal:
```powershell
cd frontend
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Notes
The current starter includes a working dashboard UI and a minimal Express/MongoDB health API. We will extend authentication, transactions, budgets, savings goals, analytics, tests, Docker and CI/CD in subsequent iterations.
